## Platform overview

CloudStack is a cloud-native API platform offering:

- **Compute** — spin up jobs, containers, and serverless functions
- **Storage** — object and block storage with global CDN
- **Auth** — OAuth 2.0 / API key authentication with fine-grained scopes
- **Observability** — built-in metrics, logs, and distributed tracing

All services are accessible via the REST API at `https://api.cloudstack.io/v2/`.
